# 探索性提问提示词

## 当 AI 主动发现潜在需求时的对话模板

### 基于数据分析的发现
```
💡 **建议**：我注意到 [观察到的现象]。

**分析**：[这意味着什么]

**建议方案**：[简要描述建议的功能/改进]

**预期收益**：[解决什么问题，带来什么价值]

你觉得这个方向值得探讨吗？如果感兴趣，我们可以按需求工程流程来推进。
```

### 基于技术债务的发现
```
🔧 **技术建议**：我发现 [技术问题]。

**当前影响**：[对开发/维护/性能的影响]

**建议改进**：[具体的重构/优化方案]

**工作量预估**：[S/M/L/XL]，预计 [X] 小时

建议在下次迭代中处理，避免债务继续累积。
```

### 基于用户行为的推测
```
📊 **观察**：从 [数据来源] 看，[用户行为模式]。

**推测**：用户可能 [需求/痛点]。

**建议**：考虑添加 [功能] 来 [解决方案]。

需要我进一步分析数据验证这个推测吗？
```

## 触发频率控制
- 同一类建议至少间隔 2 周
- 用户明确拒绝过的建议，至少等 1 个月
- 每次只提 1 个建议（不要信息过载）
