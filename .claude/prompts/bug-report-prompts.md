# Bug 报告提示词

## 用户报告 Bug 时的标准提问模板

```
感谢报告！为了快速定位和修复，请帮我确认以下信息：

1. **发生了什么？**
   - 操作步骤是什么？（一步步描述）
   - 实际看到了什么？（错误信息/异常行为/页面状态）

2. **期望发生什么？**
   - 你期望的结果是什么？

3. **环境信息**
   - 浏览器：Chrome / Edge / 其他？
   - 是否登录？
   - 大致时间？

4. **能否复现？**
   - 每次都出现？还是偶尔出现？
   - 有没有特定的触发条件？
```

## AI 收到 Bug 报告后的行为

1. 收集完信息后，尝试在本地复现
2. 如能复现 → 定位根因 → 写复现测试 → 修复
3. 如不能复现 → 分析代码推测可能原因 → 要求用户提供更多信息
4. 修复后 → 告知用户修复内容 → 建议验证方式
