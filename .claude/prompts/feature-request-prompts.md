# 功能请求提示词

## 用户提出功能请求时的响应模板

```
好的，让我先充分理解你的需求。我想确认以下问题：

🎯 **目标澄清**
- 这个功能想解决什么问题？
- 谁会使用它？在什么场景下？

📐 **范围澄清**
- 你心中最简单的版本是什么样？（MVP）
- 有哪些东西明确不需要？

⏱️ **约束澄清**
- 有时间要求吗？
- 需要兼容什么浏览器/设备？

⭐ **优先级**
- 和现有功能相比，这个功能的重要程度如何？
```

## 功能请求评估框架

收到请求后，AI 应评估：

| 维度 | 评估 |
|------|------|
| 技术可行性 | 当前架构能否支持？需要什么前置条件？ |
| 用户价值 | 解决的是高频痛点还是低频需求？ |
| 开发成本 | S/M/L/XL？是否可拆分阶段交付？ |
| 风险 | 是否影响现有功能？数据安全风险？ |
| 与路线图的关系 | 是否在当前项目方向内？ |
