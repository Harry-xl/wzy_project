# Skill: 安全重构 (refactor)

> 在不改变外部行为的前提下，改善代码的内部结构

## 触发条件
- 函数/文件过长（>200 行）
- 重复代码
- 命名不清晰
- 耦合过紧

## 工作流程

### 第一步：确认安全网
```bash
python -m pytest tests/ -v --cov  # 确保现有测试通过
```
如果目标代码无测试覆盖 → 先用 `write-tests` skill 补充测试

### 第二步：实施重构
常见手法：
- **提取函数**：一段逻辑有独立语义 → 提取为函数
- **提取类**：一组函数操作同一数据 → 提取为类
- **重命名**：名称不反映意图 → 改名
- **消除重复**：相同逻辑出现 3 次以上 → 提取共用

每次只做一种重构，提交一个 commit。

### 第三步：验证
```bash
python -m pytest tests/ -v  # 全部通过
```
如果任何测试失败 → 立即回退，分析原因，再重新重构

## 重构原则
- 每次改动最小化
- 保持代码随时可运行
- 不混入功能变更
- 重构完成后运行完整测试套件
