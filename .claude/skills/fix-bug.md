# Skill: 修复 Bug (fix-bug)

> 标准化的 Bug 修复流程：复现 → 定位根因 → 写测试 → 修复 → 验证

## 工作流程

### 第一步：理解 Bug
1. 要求用户描述：发生了什么？期望发生什么？如何复现？
2. 查看相关代码和日志
3. 尝试复现 Bug（如果可以运行项目）

### 第二步：定位根因
1. 找到 Bug 发生的具体代码行
2. 分析为什么会产生 Bug（逻辑错误/边界条件/数据问题/竞态条件）
3. 检查是否有其他类似场景存在同类问题

### 第三步：写复现测试
```python
def test_<描述>_reproduces_bug():
    """复现 Bug 的测试用例"""
    # 构造触发 Bug 的条件
    # assert 当前（错误）行为
    ...
```
运行确认测试失败：`python -m pytest tests/ -k "test_xxx" -v`

### 第四步：修复
1. 修改代码修复 Bug
2. 运行测试确认通过
3. 确保不引入新问题（运行完整测试套件）

### 第五步：回归验证
```bash
python -m pytest tests/ -v  # 全部通过
```

## 提交信息格式
```
fix: <Bug 描述>

根因: <根本原因>
修复: <修复方式>
```
