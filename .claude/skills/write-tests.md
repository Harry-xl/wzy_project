# Skill: 编写测试 (write-tests)

> 为目标代码生成缺失的测试用例

## 工作流程

### 第一步：分析目标
1. 阅读目标代码，理解输入/输出/边界条件/异常路径
2. 检查现有测试覆盖情况
3. 确定测试类型（单元/集成/两者）

### 第二步：编写测试
1. 遵循 `.claude/rules/testing-rules.md` 的规范
2. 覆盖场景：
   - 正常路径 (happy path)
   - 边界条件 (空输入、极值、零值)
   - 异常路径 (无效输入、依赖失败)
   - 并发场景（如适用）
3. 使用现有 fixtures（`tests/conftest.py`）

### 第三步：验证
```bash
python -m pytest tests/ -v --cov=<目标模块> --cov-report=term
```

### 第四步：检查覆盖率
确保新测试的代码覆盖率达到 90%+

## 测试优先级
1. 关键业务逻辑（选题策略、画像更新、密码哈希）
2. API 端点（输入验证、业务调用、返回格式）
3. 前端核心功能（可选，需要浏览器测试环境）
4. 工具函数
